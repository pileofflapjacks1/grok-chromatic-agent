# Contributing

Contributions are welcome.

## Good First Contributions

- Additional starter templates (with READMEs and checklists)
- More example prompts
- Troubleshooting entries for issues you hit
- Improvements to the scaffolder or helper scripts
- Better hardware-limit notes or audit checks

## How to Contribute

1. Fork the repo.
2. Create a branch.
3. Make your changes.
4. Update `CHANGELOG.md`.
5. Open a pull request.

## Guidelines

- Prefer GB Studio workflows.
- Keep hardware limits in mind.
- Do not include copyrighted Nintendo assets.
- Warn clearly before any cartridge-flash instructions.
- Test Python scripts with `python script.py --help` or a dry run when possible.

## Advanced Ideas

See `docs/advanced.md` for MCP server and GBDK directions.
